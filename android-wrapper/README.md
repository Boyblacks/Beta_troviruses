# TROVIRUSES Android Wrapper

This is a minimal Android WebView wrapper around the existing TROVIRUSES HTML/CSS/JavaScript app.

The original web app is copied under:
`app/src/main/assets/web/`

The original web source is kept separate from the Android wrapper.

Build the debug APK on a machine or CI runner with JDK + Android SDK:
`./gradlew assembleDebug`

Output:
`app/build/outputs/apk/debug/app-debug.apk`
